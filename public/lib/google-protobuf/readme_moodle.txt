Google Protobuf
===============

How to upgrade?

1. Download the zip file of the latest version from https://github.com/protocolbuffers/protobuf/releases
2. Extract the zip file
3. Copy the `php/src` folder
4. Copy the README.md and composer.json files from the root of the project
5. Update public/lib/thirdpartylibs.xml with the latest version
